# 2026-11-01 — WebAppPoliMusicV2

## Song.aspx completada (capa de datos + diseño)

**Esquema real de `TBL_SONG`** (tomado de `Web_Avanzadas/BDD_PoliMusic.sql`):
`ID_SONG` int IDENTITY PK, `SONG_NAME` varchar(50) NOT NULL,
`SONG_PATH` varchar(255) NOT NULL, `PLAYS` int NULL.
Las rutas se guardan con prefijo `~/` (ej. `~/songFiles/bensound-adventure.mp3`).

**Archivos creados**
- `Entities/Song.cs` — ID, SongName, SongPath, Plays (mismo estilo que `Entities/User.cs`).
- `DAL/Song.cs` — CRUD (`Save`, `Read`, `GetAll`, `GetById`, `Update`, `Delete`)
  + `IncreasePlays`, `GetTotalPlays`, `CheckExistSongPath`. Devuelve `DataTable` y
  `List<Entities.Song>` (igual que el DAL de User, que usa DataTable).
- `BLL/Song.cs` — pass-through al DAL + `ValidateSong` / `ValidateDuplicated`.
- `Handlers/PlayCounter.ashx` (+ `.cs`) — `IRequiresSessionState`; incrementa PLAYS
  vía AJAX y devuelve `{"id":n,"plays":n}` sin recargar la página.
- `Content/PoliMusic.css` y `Content/PoliMusic.js` — tema e interacción del reproductor.
- `Song.aspx` / `Song.aspx.cs` / `Song.aspx.designer.cs` — reemplazaron la pantalla de ejemplo.
- `WebAppPoliMusicV2.csproj` — se registraron todos los archivos (Song.aspx NO estaba
  incluido en el proyecto).

**Decisiones técnicas**
- Tema oscuro tipo Spotify: base morado/azul (`#7c3aed → #2563eb`) con gradientes
  rojo/fucsia (`#ef4444 → #d946ef`) en logo, nombre del usuario, botones y barra de progreso.
- Reproductor propio por fila (play/pausa, tiempo, seek, volumen, mute) con un solo
  audio activo a la vez; el contador de reproducciones se actualiza sin postback.
- **Ojo:** en plantillas de `Repeater`, `<%# %>` solo funciona como contenido de un
  elemento, NO dentro de atributos de HTML plano. Por eso el id y el src del audio
  viajan en `<span hidden>` y el JS los lee con `textContent`.
- `Song.aspx` usa rutas relativas (`Content/...`, `Logout.aspx`) para no depender de
  bloques `<%= %>` dentro de `<head runat="server">`.
- `preload="metadata"` para mostrar duraciones; los archivos inexistentes solo se
  marcan como faltantes cuando el usuario intenta reproducirlos.
